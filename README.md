# Vitória Ribeiro — Portfólio Profissional

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript puro, apresentando minha trajetória, conhecimentos e projetos na área de Tecnologia da Informação.

## Tecnologias Utilizadas

- **HTML5** — estrutura semântica e acessível
- **CSS3** — design system com variáveis, dark mode e responsividade
- **JavaScript ES6+** — interações, filtros, animações e persistência de tema

## Funcionalidades

- Dark Mode com preferência salva via `localStorage`
- Menu mobile com overlay e navegação por teclado
- Filtro de projetos com animação suave
- Scroll suave e navegação ativa
- Animações de entrada com `IntersectionObserver`
- Botão voltar ao topo
- Respeita `prefers-reduced-motion`

## Como Utilizar

Abra o arquivo `index.html` diretamente no navegador. Nenhum servidor local é necessário.
